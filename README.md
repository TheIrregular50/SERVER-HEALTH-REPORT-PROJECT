THIS IS A SERVER-HEALTH-REPORT SCRIPT THAT CHECKS SERVER HEALTH (MEMORY AVAILABLE, CPU LOAD,AND DISK USAGE AGAISNT THE LIMIT YOU SET ALONG WITH NGINX SERVICE STATUS DAILY WITH CRON

1. HOW TO RUN IT: MANUALLY - ./HEALTH-REPORT.SH.    CRON RUNS IT AUTOMATICALLY AT 7AM DAILY AND APPENDS EACH OUTPUT AND ERRORS TO A LOG FILE WITH  " 0 7 * * * /HOME/USER/DIR/HEALTH-REPORT.SH >> /HOME/USER/LOGS/HEALTH-REPORT.LOG 2>&1

2. EXIT CODES: EXIT $STATUS RUNS AS THE EXIT CODE, IF ALL CHECKS PASSES, EXIT CODE IS 0 AND IF ONE OR MORE CHECK FAILS, EXIT CODE IS 1

3. WHAT I LEARNT? I LEARNT HOW TO SET UP SCHEDULED CHECKS THAT WRITE A LOG WHICH IS THE SIMPLEST FORM OF MONITORING TO HELP WITH FIXES WHEN SOMETHING BREAKS.
